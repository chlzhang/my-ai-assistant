核心流程 — 查询路径

  • • 用户提问 → 网页界面 → API 网关
  • • 查询智能体解析用户意图
  • • 向量数据库进行相似度搜索（ANN）
  • • 重排序器对 Top-K 结果重新排序
  • • 大模型结合上下文生成答案
  • • 响应返回给用户

数据摄入 — 索引路径

  • • 文档加载（PDF / 网页 / API）
  • • 文本切分为小块（Chunking）
  • • 向量嵌入模型生成向量
  • • 索引写入器写入向量库 + 文档库
  • • 元数据存储用于溯源
  • • Kafka 缓冲管道各阶段消息

核心技术选型

  • • 向量数据库：Milvus、Qdrant、Pinecone
  • • 嵌入模型：text-embedding-3、BGE
  • • 大模型：GPT-4o、Claude 3.5、通义千问
  • • 重排序：BGE-Reranker、Cohere
  • • 文档存储：MinIO/S3 + MongoDB
  • • 消息总线：Kafka / RabbitMQ
